IP 分数怎么算？Ping100 评分方法

维护：Ping100 · 更新于 2026-10-26

Ping100 的 IP 分数是本站规则模型的参考值，满分 100，越高表示模型识别的风险信号越少；它不是任何社交平台的官方评分，也不能保证账号安全或服务可用。

01评分输入

模型使用第三方 IP 风险与威胁分、VPN/代理/Tor 等标签、机房或移动网络类型、共享人数估算、服务探测以及 UDP/QUIC 信号。各来源可能存在延迟、误判或缺失。

02计算与展示

内部风险值限制在 0–100，页面展示分数为 100 减去风险值。综合风险按 YouTube 45%、TikTok 35%、Instagram 10%、X 10% 加权。TikTok 分支取主要风险项的最大值，Instagram 分支合并主风险与附加项，YouTube/X 分支采用加权累加。

03关键规则与局限

bogon、Tor、恶意标签将内部风险至少提高至 100，滥用标签至少提高至 95。第三方风险与威胁分取可用值均值，再乘机房 0.18、其他网络 0.25。共享人数区间由网络标签、地址段、反向解析、预置样本及可用观测等推断，不是实际在线人数统计。缺失信号可能不产生扣分，因此高分不代表已充分验证。

04如何使用结果

先看数据是否完整，再检查具体标签和网络出口。平台分数中的差异来自本站设置的不同权重，不代表平台披露过这些规则。服务探测失败也可能由超时、地区或浏览器限制引起。请结合实际连接测试复核。

05方法版本

本文对应当前代码中的 public/ipq/risk.js（computePlatformRisks）与 public/main.js 的展示转换。更新规则时应同步更新本文。
